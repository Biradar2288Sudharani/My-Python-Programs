Question 1: Explain your project.
"My project is a Face Recognition Attendance System developed using Python. The main objective is to automate student attendance 
using face recognition instead of manual attendance.
The application provides student registration where user details like ID, name, roll number, department, phone number, email, and address are stored.
After registration, the system captures multiple face images through the webcam and stores them for training.
I used OpenCV's LBPH Face Recognizer to train the model. During attendance, the webcam detects and recognizes students in real time, then automatically 
marks attendance in a CSV file and database.
I also integrated attendance analytics using Matplotlib to generate monthly and subject-wise attendance reports.
Additionally, I integrated the Twilio WhatsApp API to automatically send attendance notifications to parents. Students with attendance 
above 95% receive a congratulatory message, while those below 75% receive a warning message."

11. Find Even and Odd Numbers ⭐⭐⭐
numbers = [1, 2, 3, 4, 5, 6]

for num in numbers:
    if num % 2 == 0:
        print(num, "Even")
    else:
        print(num, "Odd")
🎤 Explanation

“I iterate through every number in the list. I use the modulus operator to check the remainder when dividing by 2. If the remainder is zero, the number is even; otherwise, it is odd.”

12. Sum of Digits ⭐⭐⭐
n = 12345

total = 0

while n > 0:
    digit = n % 10
    total += digit
    n = n // 10

print(total)
🎤 Explanation

“I initialize total to zero. The modulus operator extracts the last digit. I add that digit to total. Then integer division by 10 removes the last digit. I repeat this until the number becomes zero.”

For 12345:

5 → 4 → 3 → 2 → 1

Result:

15
13. Reverse a Number ⭐⭐⭐
n = 1234

reverse = 0

while n > 0:
    digit = n % 10
    reverse = reverse * 10 + digit
    n = n // 10

print(reverse)
🎤 Explanation

“I extract the last digit using % 10. Then I shift the existing reverse number one position to the left by multiplying it by 10 and add the extracted digit. Finally, I remove the last digit from the original number using // 10.”

Output:

4321
14. Check Armstrong Number ⭐⭐⭐
n = 153

total = 0
temp = n

while temp > 0:
    digit = temp % 10
    total += digit ** 3
    temp = temp // 10

if total == n:
    print("Armstrong")
else:
    print("Not Armstrong")
🎤 Explanation

“I store the original number in n and make a temporary copy because I need the original number for comparison later. I extract each digit using % 10, cube the digit, and add it to total. After processing all digits, I compare the calculated total with the original number.”

For 153:

1³ + 5³ + 3³
= 1 + 125 + 27
= 153

Therefore it is an Armstrong number.

16. Find Missing Number ⭐⭐⭐⭐

Suppose:

[1, 2, 3, 5]

Expected numbers are 1 to 5.

numbers = [1, 2, 3, 5]

n = 5

expected_sum = n * (n + 1) // 2

actual_sum = sum(numbers)

missing = expected_sum - actual_sum

print(missing)
🎤 Explanation

“I calculate the expected sum from 1 to n using the mathematical formula n * (n + 1) // 2. Then I calculate the actual sum of the list. The difference between these two sums gives me the missing number.”

Output:

4

18. Find First Non-Repeating Character ⭐⭐⭐⭐
text = "aabbcdde"

for char in text:
    if text.count(char) == 1:
        print(char)
        break

Output:

c
🎤 Explanation

“I iterate through each character and use count() to find how many times that character occurs. If the count is exactly one, it is the first non-repeating character, so I print it and use break to stop the loop.”

⚠️ Interviewer may ask:

Is this optimal?

You should answer:

“For a large string, repeatedly calling count() is inefficient. I would prefer using a dictionary to count frequencies in one pass and then find the first character whose frequency is one.”

🔥 This answer shows optimization awareness.

19. Sort a List Without sort() ⭐⭐⭐⭐
numbers = [5, 2, 8, 1, 3]

for i in range(len(numbers)):
    for j in range(i + 1, len(numbers)):
        if numbers[i] > numbers[j]:
            numbers[i], numbers[j] = numbers[j], numbers[i]

print(numbers)
🎤 Explanation

“I compare each element with the elements after it. If the current element is greater than a later element, I swap them. By repeatedly doing this, smaller values move toward the beginning of the list.”

Output:

[1, 2, 3, 5, 8]

This demonstrates your understanding of sorting logic and nested loops.

20. Find Duplicate Elements ⭐⭐⭐⭐
numbers = [1, 2, 3, 2, 4, 5, 3]

duplicates = []

for num in numbers:
    if numbers.count(num) > 1 and num not in duplicates:
        duplicates.append(num)

print(duplicates)

Output:

[2, 3]
🎤 Explanation

“I iterate through every number and check how many times it occurs using count(). If its frequency is greater than one, it is a duplicate. I also check num not in duplicates so that I don't add the same duplicate multiple times.”

🧠 Champ, THIS is how you should explain any Python program

Don't memorize 20 separate explanations. Learn this 6-step interview formula:

1️⃣ State the approach

“First, I'll explain the approach I am going to use.”

2️⃣ Explain variables

“I initialize this variable to store the result.”

3️⃣ Explain the loop

“Then I iterate through each element using a for loop.”

4️⃣ Explain the condition

“Inside the loop, I check this condition.”

5️⃣ Explain the update

“If the condition is satisfied, I update the result.”

6️⃣ Give complexity

“The time complexity is O(n) because I traverse the input once.”

🔥 Example: Interviewer gives you this

Don't just say:

Instead say:

“First, I have a list of numbers. I initialize largest with the first element because I need an initial value for comparison. Then I iterate through the list using a for loop. For every number, I compare it with the current value of largest. If the current number is greater, I update largest. After checking all elements, largest contains the maximum value, so I print it. The time complexity is O(n) because I visit each element once, and the extra space complexity is O(1).”
