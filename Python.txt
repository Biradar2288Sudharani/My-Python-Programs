Question 1: Explain your project.
"My project is a Face Recognition Attendance System developed using Python. The main objective is to automate student attendance 
using face recognition instead of manual attendance.
The application provides student registration where user details like ID, name, roll number, department, phone number, email, and address are stored.
After registration, the system captures multiple face images through the webcam and stores them for training.
I used OpenCV's LBPH Face Recognizer to train the model. During attendance, the webcam detects and recognizes students in real time, then automatically 
marks attendance in a CSV file and database.
I also integrated attendance analytics using Matplotlib to generate monthly and subject-wise attendance reports.
Additionally, I integrated the Twilio WhatsApp API to automatically send attendance notifications to parents. Students with attendance 
above 95% receive a congratulatory message, while those below 75% receive a warning message."

Question 2
Why did you choose OpenCV?
Answer
OpenCV provides image processing and computer vision functionalities. It allows real-time face detection and recognition efficiently using Python.

Question 3
Which face recognition algorithm did you use?
Answer
I used the LBPH (Local Binary Patterns Histogram) Face Recognizer because it performs well under varying lighting conditions, is easy to train, and is suitable 
for real-time face recognition applications.

Question 4
Why LBPH instead of Haar Cascade?
Answer
Haar Cascade is mainly used for face detection.
LBPH is used for face recognition.
Flow
Haar Cascade
↓
Face Detection
↓
LBPH
↓
Face Recognition

Question 14
How do you calculate attendance?
Answer
Attendance % = Present Days / Total Working Days × 100
Example
Present = 45
Total = 50
Attendance = 90%

Question 15
What challenges did you face?
Answer
During development, I faced challenges such as varying lighting conditions, multiple faces appearing in the frame, and ensuring accurate face recognition. 
I improved recognition by capturing multiple face samples for each student and training the model properly. I also handled duplicate attendance entries and 
integrated WhatsApp notifications successfully.
